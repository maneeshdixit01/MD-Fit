MD Fit Background GPS APK बनाने के चरण

1. ZIP Extract करें।
2. पूरा प्रोजेक्ट GitHub repository के root में अपलोड करें। `.github`, `native` और `scripts` फोल्डर भी जरूर अपलोड करें।
3. `main` branch में Commit करें।
4. Actions टैब खोलें और `Build MD Fit Android APK` workflow पूरा होने दें।
5. Artifacts में `MD-Fit-debug-APK` डाउनलोड करें।
6. ZIP Extract करके `app-debug.apk` फोन में इंस्टॉल करें।

फोन पर परीक्षण:
- MD Fit खोलें और Start Activity दबाएँ।
- Location permission Allow करें; बेहतर GPS के लिए Precise location चुनें।
- Notification permission भी Allow करें।
- ऊपर MD Fit का लगातार tracking notification दिखना चाहिए।
- स्क्रीन लॉक करके बाहर कुछ मिनट चलें/दौड़ें।
- ऐप फिर खोलें; route और distance अपडेट होनी चाहिए।
- Pause/Finish से GPS tracking बंद करें।

ध्यान दें: Start Activity ऐप खुला रहने और स्क्रीन पर दिखने के दौरान शुरू करें। यह Debug APK है, Play Store के लिए Signed AAB नहीं।
